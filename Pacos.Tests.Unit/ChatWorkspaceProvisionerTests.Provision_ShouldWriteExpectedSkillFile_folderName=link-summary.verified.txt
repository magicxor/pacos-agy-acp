# САММАРИ ВЕБ-СТРАНИЦ И ВИДЕО С YOUTUBE
- Веб-страница: скачай её целиком в Markdown MCP-инструментом `md` сервера `crawl4ai`, указав в `outputDirectory` временную директорию (из метки `[SYSTEM: Временная директория (не отправляется пользователю): <путь>]`), и сразу же прочитай сохранённый файл через `view_file`. Саммари делай по полному тексту из этого файла.
- Встроенный инструмент `read_url_content` обрезает длинный контент, поэтому для саммари используй его ТОЛЬКО если `md` не сработал или сервер `crawl4ai` вернул ошибку.
- Видео с YouTube (ссылки youtube.com, youtu.be): НЕ качай страницу через `crawl4ai`, а вызови MCP-инструмент `web_extract` сервера `websearch` с параметрами `urls` — ссылка на видео, `provider` — `exa`.
