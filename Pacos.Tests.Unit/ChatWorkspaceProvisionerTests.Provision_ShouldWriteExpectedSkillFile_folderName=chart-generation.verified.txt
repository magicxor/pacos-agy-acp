# ГРАФИКИ И ДИАГРАММЫ (MCP quickchart)
- Чтобы построить график или диаграмму (`bar`, `line`, `pie`, `doughnut`, `radar`, `scatter` и т.д.), используй MCP-инструмент `create_chart` сервера `quickchart`.
- Параметр `chart` — конфигурация Chart.js 4 в виде JSON, переданная СТРОКОЙ: весь конфиг целиком лежит в одном строковом аргументе, объектом его класть нельзя. Используй ТОЛЬКО синтаксис Chart.js 4 (`options.scales.x` / `options.scales.y`, `options.plugins.title` / `options.plugins.legend`); синтаксис Chart.js 2 (`scales.xAxes`, тип `horizontalBar`) не поддерживается — для горизонтальных `bar` используй `"indexAxis": "y"`. Опциональные параметры: `backgroundColor`, `format` (`png` по умолчанию; `svg`, `pdf`).
- Фон по умолчанию прозрачный; для отправки картинки в чат указывай `backgroundColor`, например `white`.
- `width` и `height` НЕ задавай: сервер сам подберёт холст под то, что рисуется — длинная сторона 1280, вторая по пропорциям (карта получит форму карты, `bar`/`line` альбом, `pie` квадрат). Задашь только одну сторону — вторая посчитается от неё. Указывай размеры явно, только если нужен конкретный формат картинки.
- По умолчанию всегда настраивай плагин `datalabels` так, чтобы текст был чёрным с белой обводкой.
- Функций в конфиге НЕТ: сервер не исполняет JS, и строка с исходником функции (`"formatter": "function(v) { ... }"`, `ticks.callback`, цвет-функция) вернёт ошибку 400 с именем опции. Всё, для чего обычно пишут функции, задаётся значениями: текст у конкретной точки — поле `label` в объектной точке `{ "x": "Янв", "y": 12, "label": "12%" }` (массив строк даёт несколько строк подписи); числа на оси — `ticks.format` с опциями `Intl.NumberFormat` (`{ "style": "percent" }`, `{ "style": "currency", "currency": "USD" }`, `{ "notation": "compact" }`); цвет по условию — массив цветов по точкам в `backgroundColor`. Дефолтные подписи уже сами правильно печатают точки `{ x, y }` (значение по оси значений), пузыри `{ x, y, r }` (радиус), этапы воронки (название этапа и значение) и строки гео-данных (название региона и значение) — `label` нужен только чтобы изменить этот текст, а не чтобы он вообще появился.
- Результат сохраняется в директорию из параметра `outputDirectory`: указывай выходную директорию (пути бери из меток `[SYSTEM: ...]`).
- Если инструмент вернул ошибку, покажи пользователю её текст.
- Ошибка «is not valid JSON» значит, что конфиг не разобрался как JSON, и почти всегда потому, что он ОБОРВАН: в самом конце не хватает закрывающей `}` или `]`. Пересчитай скобки и отправь конфиг заново целиком. Форму вызова при этом НЕ меняй: `chart` так и остаётся строкой — переложив его в объект, ты получишь вместо внятной ошибки глухое `An error occurred invoking 'create_chart'.`, по которому уже ничего не починить.
- Кроме ошибок инструмент может вернуть поле `warnings`: график нарисован, но с ним что-то не так. Прочитай их и либо перерисуй график, либо объясни в ответе, почему так и надо.
- Карты (гео: `choropleth`, `bubbleMap`) — отдельный навык geo-maps (`.agents/skills/geo-maps/SKILL.md`). ОБЯЗАТЕЛЬНО прочитай его перед тем, как строить карту: без его правил карта отрисуется сломанной.
- Делай графики максимально наглядными:
  1. Тип — по смыслу данных, например: сравнение категорий — `bar`; динамика во времени — `line`; доли целого — `pie` / `doughnut` (до ~6 долей); категории с подкатегориями — двухуровневый `doughnut` (два dataset); поэтапная воронка — `funnel`; зависимость двух величин — `scatter`. Карту бери, только когда важна географическая привязка: распределение по многим странам/регионам («где больше, где меньше») — `choropleth`, данные в конкретных точках (города, порты, месторождения) — `bubbleMap`; сравнение показателя у нескольких конкретных стран — это обычный `bar`, а не карта.
  2. Значения показывай прямо у столбиков и точек плагином `datalabels`, а не только на оси — как именно и что делать, когда подписей слишком много, см. раздел «Подписи значений».
  3. Цвета — осмысленные для данных: цвета флагов для стран, розовый/голубой для девочек/мальчиков, зелёный/красный для роста/падения; иначе — контрастная палитра, а не один цвет на всё.
  4. Обязателен заголовок, крупные шрифты (заголовок ~20, подписи ~14), подписи осей; легенду убирай, если она дублирует подписи.
  5. НИКОГДА не используй `\n` и другие escape-последовательности в заголовках и подписях — коды символов не поддерживаются, и текст выведется буквально (косая черта и буква n). Для переноса строки передавай текст массивом строк, например `"text": ["Первая строка", "Вторая строка"]`; многострочная подпись значения — массив строк в поле `label` точки (см. «Подписи значений»).

## Подписи значений (плагин datalabels)
Значение у столбика или точки видно сразу, значение на оси приходится проецировать глазом — поэтому по умолчанию подписывай точки данных на самом графике.
- `bar`: `"anchor": "end"`, `"align": "top"`; горизонтальный `bar` (`"indexAxis": "y"`): `"anchor": "end"`, `"align": "right"`; `line` / `scatter`: `"align": "top"`.
- Оставляй запас по оси значений, иначе верхняя подпись упрётся в край кадра: `scales.y.grace = "8%"` (у горизонтального `bar` — `scales.x.grace`).
- Подписи между собой не расталкиваются. Если их много и они наезжают друг на друга (несколько линий, десятки точек), убавляй плотность по порядку:
  1. `"display": "auto"` — плагин сам скрывает каждую подпись, которая перекрылась с уже нарисованной. Начинай с этого, обычно хватает. Скрытая подпись исчезает совсем, так что для важной точки (максимум, последнее значение) лучше следующие способы.
  2. Подписать только конец каждой линии: `datalabels` выключить, а на последнюю точку каждой серии поставить пометку `"type": "label"` (плагин annotation, раздел ниже) с текстом «серия: значение», `"position": { "x": "start", "y": "center" }` и `"xAdjust": 8`; легенду выключить, `layout.padding.right` ~120 под текст. Читается лучше легенды: подпись стоит вплотную к своей линии.
  3. От 5-6 пересекающихся линий подписи выключай совсем (`"display": false`) и полагайся на ось Y: горизонтальная сетка рисуется по умолчанию, для читаемости задай `scales.y.ticks.stepSize` и `scales.y.grid.color = "rgba(0,0,0,0.12)"`. Пользователь спроецирует точку на ось сам.
- Воронка (`funnel`) по умолчанию ВЕРТИКАЛЬНАЯ: задавай `options.indexAxis = "y"`. Тогда этапы лежат полосами сверху вниз, каждая во всю ширину кадра, и в подпись влезает длинное название этапа. Горизонтальную воронку бери только если пользователь прямо о ней просит.
- Воронка (`funnel`): подписи включены по умолчанию, и сервер сам пишет на слое название этапа (из `data.labels`) и его значение — форматер не нужен, своих осей у воронки нет вообще. В `data` клади ровно те числа, которые надо показать: значение печатается как есть, в проценты не пересчитывается.

## Пометки на графике (плагин annotation)
Когда на графике нужно отметить событие, период или конкретную точку — «здесь начался кризис», «это время карантина», «вот рекорд» — используй `options.plugins.annotation.annotations`. Это объект: ключ — произвольный id пометки, значение — сама пометка со своим `type`. Типы: `line`, `box`, `point`, `label`, `ellipse`, `polygon`, `doughnutLabel` (текст в центре бублика).
Координаты задаются В ЕДИНИЦАХ ДАННЫХ, а не в пикселях: `xMin` / `xMax` / `yMin` / `yMax` у `line` и `box`, `xValue` / `yValue` у `point` и `label`. На категориальной оси это название категории (`"1929"`) или её индекс, на линейной — число, на оси времени — дата в том же формате, что и в данных. У горизонтального `bar` (`"indexAxis": "y"`) категория лежит на оси Y: категория — это `yValue`, число — `xValue`.
Четыре рецепта, которых хватает почти всегда:
- Вертикальная отсечка через весь график: `{ "type": "line", "xMin": "1929", "xMax": "1929", "borderColor": "#c0392b", "borderWidth": 2, "borderDash": [6, 4], "label": { "display": true, "content": "Событие", "position": "start", "backgroundColor": "#c0392b", "color": "white" } }`. Одинаковые `xMin` и `xMax` дают вертикаль; одинаковые `yMin` и `yMax` — горизонтальный порог (план, средняя, рекорд).
- Выделенный период (зона): `{ "type": "box", "xMin": "1929", "xMax": "1933", "backgroundColor": "rgba(192,57,43,0.1)", "borderColor": "rgba(192,57,43,0.35)", "borderWidth": 1, "label": { "display": true, "content": "Кризис", "position": { "x": "center", "y": "start" } } }`. Заливка обязательно полупрозрачная, иначе она закроет собой линию графика.
- Стрелка с пояснением: та же `line` между двумя произвольными точками плюс `"arrowHeads": { "end": { "display": true, "fill": true, "length": 12, "width": 8 } }`. Остриё рисуется на конце (`xMax`, `yMax`) — туда пиши точку графика, на которую показываешь, а в (`xMin`, `yMin`) — место, где висит подпись.
- Выноска к точке: маркер `{ "type": "point", "xValue": "1933", "yValue": 99, "radius": 6, "backgroundColor": "..." }` плюс отдельная плашка `{ "type": "label", "xValue": "1933", "yValue": 99, "yAdjust": -34, "content": [...], "callout": { "display": true, "borderWidth": 2 } }` — `callout` дорисует ножку от плашки к точке, а `yAdjust` отведёт плашку от неё.
Правила:
- Многострочный текст пометки — массив строк: `"content": ["Дно рынка", "-89% от пика"]`. `\n` не работает и здесь (см. пункт 5 выше).
- Пометки не расталкиваются ни между собой, ни с подписями `datalabels`. Если плашки налезают друг на друга, разводи их вручную: `position` (`"start"`, `"center"`, `"end"` или `{ "x": ..., "y": ... }`) плюс сдвиги в пикселях `xAdjust` и `yAdjust`. На графике с пометками `datalabels` обычно лучше выключить совсем: `options.plugins.datalabels.display = false`.
- Плашка `"type": "label"` центрируется НА своей точке. Поэтому подпись к столбику, поставленная в его значение, ложится прямо на столбик и на его подпись значения — получается месиво. Комментарий к столбику давай не пометкой, а самой подписью `datalabels`: запиши точки серии объектами `{ "x": "2020", "y": 12 }`, а нужной дай массив в `label` — `{ "x": "2021", "y": 15, "label": ["15%", "рекорд десятилетия"] }` — и плагин отодвинет весь текст от столбика сам. Текста в подписи станет больше, поэтому расширяй запас по оси значений (`grace` или `suggestedMax`).
- Если плашка `annotation` всё же нужна, ставь её в СВОБОДНОЕ поле кадра, а не в точку данных: `"position": { "x": "start", "y": "center" }` прижимает левый край плашки к точке, а `"xAdjust": 60` уводит её за конец столбика и за его подпись значения. Свободное поле сначала создай: `suggestedMax` по оси значений с запасом ~40% от максимума.
- 1-4 пометки на график, не больше: график не стенгазета, остальные пояснения давай текстом в ответе.
- Если по оси X годы, делай ось категориальной (`"labels": ["1925", "1926", ...]`, данные простым массивом): на линейной оси Chart.js печатает годы с разделителем тысяч — «1,925» вместо «1925».

## Пример графика с пометками
Проверенный рабочий конфиг: зона, вертикальная отсечка, стрелка и выноска на одной картинке. Строгий JSON, ни одной функции.
```json
{
  "type": "line",
  "data": {
    "labels": ["1925", "1926", "1927", "1928", "1929", "1930", "1931", "1932", "1933", "1934", "1935", "1936"],
    "datasets": [
      {
        "label": "Dow Jones",
        "data": [137, 157, 200, 300, 248, 164, 77, 60, 99, 104, 144, 180],
        "borderColor": "#1f4e79",
        "borderWidth": 3,
        "pointRadius": 0,
        "tension": 0.25
      }
    ]
  },
  "options": {
    "layout": { "padding": { "top": 10, "right": 30, "bottom": 10, "left": 10 } },
    "scales": {
      "y": {
        "beginAtZero": true,
        "title": { "display": true, "text": "Индекс, пунктов", "font": { "size": 14 } }
      }
    },
    "plugins": {
      "title": { "display": true, "text": "Dow Jones, 1925-1936", "font": { "size": 20 } },
      "legend": { "display": false },
      "datalabels": { "display": false },
      "annotation": {
        "annotations": {
          "depression": {
            "type": "box",
            "xMin": "1929",
            "xMax": "1933",
            "backgroundColor": "rgba(192,57,43,0.1)",
            "borderColor": "rgba(192,57,43,0.35)",
            "borderWidth": 1,
            "label": {
              "display": true,
              "content": "Великая депрессия",
              "position": { "x": "center", "y": "start" },
              "color": "#7b241c",
              "font": { "size": 14, "weight": "bold" }
            }
          },
          "crash": {
            "type": "line",
            "xMin": "1929",
            "xMax": "1929",
            "borderColor": "#c0392b",
            "borderWidth": 2,
            "borderDash": [6, 4],
            "label": {
              "display": true,
              "content": ["Чёрный вторник", "29 октября 1929"],
              "position": "start",
              "backgroundColor": "#c0392b",
              "color": "white",
              "font": { "size": 12 }
            }
          },
          "bottomArrow": {
            "type": "line",
            "xMin": "1934",
            "yMin": 40,
            "xMax": "1932",
            "yMax": 58,
            "borderColor": "#111",
            "borderWidth": 2,
            "arrowHeads": { "end": { "display": true, "fill": true, "length": 12, "width": 8 } },
            "label": {
              "display": true,
              "content": ["Дно рынка: 41 пункт", "-89% от пика"],
              "position": "start",
              "backgroundColor": "rgba(17,17,17,0.85)",
              "color": "white",
              "font": { "size": 12 },
              "xAdjust": 55
            }
          },
          "newDealPoint": {
            "type": "point",
            "xValue": "1933",
            "yValue": 99,
            "radius": 6,
            "backgroundColor": "rgba(39,174,96,0.9)",
            "borderColor": "white",
            "borderWidth": 2
          },
          "newDealLabel": {
            "type": "label",
            "xValue": "1933",
            "yValue": 99,
            "yAdjust": -34,
            "content": ["Новый курс", "Рузвельта"],
            "backgroundColor": "rgba(39,174,96,0.9)",
            "color": "white",
            "font": { "size": 12 },
            "padding": 5,
            "callout": { "display": true, "borderColor": "#27ae60", "borderWidth": 2, "margin": 4 }
          }
        }
      }
    }
  }
}
```
